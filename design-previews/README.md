# Colour scheme previews

Screenshots of the four schemes on trial, taken 29 Sep 2026 from the branch
build. Not part of the website; delete this folder once a scheme is chosen.

- `1-heroes-desktop.jpg`: the hero in each scheme at 1440px, in a 2x2 grid:
  almond, linen / blackberry, petal
- `2-heroes-phone.jpg`: the same at 390px, left to right in that order
- `3-page-*.jpg`: the full page in each scheme

On the live site each scheme opens with `?palette=almond`, `linen`,
`blackberry` or `petal` after the page URL.
